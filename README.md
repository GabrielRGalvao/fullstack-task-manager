# Fullstack Task Manager 🚀

Aplicativo de gerenciamento de tarefas em tempo real desenvolvido para portfólio.

## 🛠 Tecnologias
- **Frontend:** React Native com Expo e TypeScript.
- **Backend/Database:** Convex (Banco de dados reativo).
- **Estilização:** StyleSheet nativo.

## ✨ Funcionalidades
- CRUD completo de tarefas (Adicionar, Listar, Marcar como concluída e Excluir).
- Atualização em tempo real entre dispositivos.
- Feedback visual de prioridade e status.

## 🚀 Como rodar
1. Clone o repositório.
2. Instale as dependências com `npm install`.
3. Inicie o backend com `npx convex dev`.
4. Inicie o app com `npx expo start`.
